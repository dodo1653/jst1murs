# jst1murs

Personal site for Jst ([@jst1murs](https://x.com/jst1murs)): receipts, rules, inbox and recent posts, in an editorial paper style.

Static HTML, no build step. Open `index.html`, or deploy the folder to any static host (Vercel, Netlify, GitHub Pages).

- `index.html`: the page (styles and script inline)
- `img/`: his picture and the PnL / chart screenshots from his posts

Everything on the page comes from his public posts on X. Not financial advice.
